## 8. معيار إغلاق أي مسار

لا يُعتبر المسار مكتملًا لمجرد أن الواجهة تبدو جيدة أو أن build نجح. الإغلاق يتطلب:
- معايير القبول الوظيفية متحققة باختبارات مناسبة.
- اختبارات regression للبيانات والحالات الحدية.
- responsive + keyboard/screen reader حسب طبيعة الميزة.
- مراجعة أمن/خصوصية/مصادر/حقوق حسب النطاق.
- PR diff نظيف ولا يوجد تداخل غير محلول.
- Quality Gate قابل للفحص ومرتبط بالـ exact head SHA.
- handoff موثق وتحديث مركزي بعد التحقق.
- فصل حالة CI عن Preview وProduction وGoogle AI Studio sync وعن اختبار الجهاز الحقيقي.
