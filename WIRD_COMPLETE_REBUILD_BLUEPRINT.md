- **Firebase & Security Rules:**
  - Canonical project: `wird-quran-app`, `(default)` Firestore database.
  - `firestore.rules`: strict UID + `email_verified == true` enforcement, allowlisted collections, transactional compare-and-set monotonic `revision == baseRevision + 1`, immutable `/events/{eventId}`, `allow delete: if false`, default-deny.
  - `tombstoneReconciliationService.ts`: deterministic clock-independent anti-resurrection reconciliation.

### 3.2 Editorial Visual Rules (Anti-Slop Constitution)
1. **60-30-10 Color Discipline:** 60% calm canvas, 30% structural flat surfaces with `1px` hairline borders, 10% purposeful emerald/gold accent strictly at primary actions and active states.
2. **Single-Elevation Depth:** No cards nested inside bordered cards; no thick left colored accent stripes (`border-l-4`); no giant Hero Cards repeated across every page.
3. **Zero-Pill Metadata:** Static metadata (surah counts, dates, durations, statuses) renders as clean unboxed text separated by `·` with `tabular-nums`. Pill/segmented styles are reserved strictly for interactive filter/tab `<button>` controls.
4. **Typography (`2+1` Rule):** `UthmanicHafs` / `Amiri Quran` exclusively for Quranic verses; `Cairo` for Arabic UI/headings (`text-wrap: balance` on headings); monospace/tabular figures (`tabular-nums`) for pages, counts, prayer times, and metrics.
5. **Motion & Responsiveness:** View transitions settle in `<= 180ms` using compositor-only properties (`opacity`, `transform`), honoring `prefers-reduced-motion`. Mobile sticky chrome (header + bottom nav) stays `<= 15%` viewport height with `>= 44x44px` touch targets.

### 3.3 Hand-Crafted UI Primitives (`src/components/ui/`)
- `WirdPrimitives.tsx`: `WirdButton`, `WirdCard`, `WirdCardHeader`, `WirdMetadataRow`, `WirdSegmentedTabs`, `WirdEmptyState`, `WirdViewSkeleton`, `WirdSheet`.
- `ThemeCustomizerSheet.tsx`: Live theme preset, Light/Dark mode, layout density (`comfortable` | `compact`), and corner radius (`refined` | `soft`) customizer with instant document-root token updates and device-local persistence (`src/services/themePreferences.ts`).
